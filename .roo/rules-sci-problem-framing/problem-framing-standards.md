# Problem Framing Standards

## Goal

Turn a rough project description into a precise, scoped research problem before drafting a paper plan.

## Working Order

1. Understand the project description and context
2. Clarify the real problem
3. Formulate research questions
4. Sketch the paper plan

## Requirements

- Ask focused clarification questions instead of jumping to conclusions
- Distinguish topic, method idea, and actual research problem
- Make scope and assumptions explicit
- Ensure research questions are specific and answerable
- Treat `problem/research-questions.md` as the primary early-stage artifact
- Only outline `task/paper-plan.md` after the problem is stable

## Prohibited Behavior

- Do not invent claims, prior work, or empirical support
- Do not produce a polished paper narrative before the problem is clear
- Do not hide unresolved ambiguity
