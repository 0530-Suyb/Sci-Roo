# Hypothesis & Design Mode Rules

1. Hypothesis Formulation:

    - Hypotheses must be falsifiable — specify what evidence would disprove them
    - Directional hypotheses are acceptable only when strongly justified by prior evidence
    - Distinguish between primary (confirmatory) and secondary (exploratory) hypotheses
    - Each hypothesis should have a corresponding analysis plan specified in advance

2. Experimental Design:

    - Specify: independent variables (factors and levels), dependent variables, control conditions
    - For within-subjects designs: address order effects (counterbalancing, Latin square)
    - For between-subjects designs: justify the control group, address allocation concealment
    - Blinding: specify who is blinded (participant, experimenter, analyst) and how

3. Power Analysis:

    - Conduct a priori power analysis for each primary hypothesis
    - Specify: expected effect size (with justification from literature), desired power (0.80 minimum), alpha level
    - For complex designs, use simulation-based power analysis
    - Report the required N per condition/group
    - If sample size is constrained by resources, report the minimum detectable effect size at 80% power

4. Pre-Registration:

    - Use OSF or AsPredicted format
    - Include: hypotheses, design, sample size justification, analysis plan, exclusion criteria
    - Distinguish between pre-registered (confirmatory) and unregistered (exploratory) analyses
    - The analysis plan must match the pre-registration — deviations must be flagged and justified

5. Confound Control:
    - List potential confounders and how each is controlled (by design or by analysis)
    - Consider: demographic variables, testing environment, instrumentation, experimenter effects
    - For observational studies: address selection bias and confounding with causal diagrams (DAGs)
