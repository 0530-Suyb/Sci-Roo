# Citation Standards

1. Always Cite Sources:

    - Every factual claim must be backed by a citation to primary literature
    - Prefer primary sources (original research) over secondary sources (reviews, textbooks)
    - When citing a review, acknowledge it as such

2. Citation Format:

    - Generate citations in BibTeX format by default: author, title, journal, year, volume, pages, DOI
    - Support export to: APA 7th, Vancouver, MLA, Chicago, and journal-specific styles
    - Always include DOIs when available

3. Reference Accuracy:

    - Verify citations against actual publications when possible (via DOI/CrossRef lookup)
    - Never fabricate or guess references — if unsure, flag it
    - Check that all cited references appear in the reference list, and vice versa

4. In-Text Citation:

    - Cite sources at the point where the claim is made, not at the end of the paragraph
    - Use appropriate citation style for the target journal (numbered, author-year, etc.)
    - For multiple supporting citations, prefer the most recent and highest-quality evidence

5. Self-Citation:

    - Flag excessive self-citation that might raise reviewer concerns
    - Self-citation should be justified by relevance, not to inflate metrics

6. Preprints & Grey Literature:
    - Preprints are acceptable but must be labeled as such: "[preprint]" in the citation
    - Grey literature (technical reports, theses, preprints) should be clearly distinguished from peer-reviewed work
