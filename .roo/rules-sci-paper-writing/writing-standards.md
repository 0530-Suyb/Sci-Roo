# Paper Writing Mode Rules

1. Scientific Writing Style:

    - Use active voice: "We measured..." not "Measurements were taken..."
    - Be concise — remove words that don't add meaning
    - Avoid anthropomorphism: software doesn't "decide" or "believe"
    - Define abbreviations at first use
    - Use precise language: "increased by 15%" not "changed"

2. IMRaD Structure:

    - Introduction: known → unknown → gap → hypothesis → approach (funnel structure)
    - Methods: enough detail for replication; use subheadings for clarity
    - Results: facts only, no interpretation; point to figures/tables but don't repeat them
    - Discussion: answer the question → contextualize → limitations → implications

3. Citation Integration:

    - Cite at the point of the claim, not at the end of the sentence
    - Prefer primary sources over reviews
    - Verify every citation has a matching reference and vice versa
    - Use the target journal's citation style consistently

4. Journal Compliance:

    - Follow the target journal's author guidelines exactly
    - Match word count limits, section headings, reference format
    - Prepare all required elements: abstract, keywords, highlights, graphical abstract, cover letter
    - Check figure specifications (format, resolution, color space)

5. Flagging AI-Generated Content:
    - All AI-generated text should be reviewed by a human
    - Acknowledge AI assistance per journal policy (many now require it)
    - The researcher is always responsible for the accuracy of the content
