# 0519 开发计划

## 本次开发目标

本次开发围绕 Sci-Roo 的“读文献 -> 写论文 -> 做实验”可信闭环展开，优先完成下面几件事：

1. 明确 Magazine 综述 MVP 所需的 AI 技能清单，并补齐对应能力边界。
2. 推进 Magazine 综述 MVP 的实操验证，产出一篇可展示的综述草稿。
3. 完善 `ReadPaper` 读文献面板的拉取、检索、候选筛选和入库能力。
4. 梳理资产层设计，统一文献、问题、实验、文本块、证据卡片等核心资产的流转关系。
5. 补齐文档体系，包括检索原理、使用说明、资产目录和流程图。
6. 进行大模型对比与选型调研，为后续科研工作流提供模型选择依据。

## 目标背景

当前项目主线分成两个时间节点：

- 2026-05-23：可运行 Demo，重点是打通“读文献 -> 写论文 -> 做实验”的可信核心闭环。
- 2026-05-30：MVP 测试版，目标是用现有工具完成一篇 Magazine 类型综述的撰写与展示。

因此，本次开发不是单点功能修补，而是围绕 MVP 交付，把能力、流程、资产和文档一起补齐。

## 重点任务拆解

### 1. 明确 Magazine 综述 MVP 所需 AI 技能

需要先把综述型科研工作拆成可复用技能：

- 文献检索
- 文献拉取
- 文献库管理
- 单篇文献分析
- 批量文献分析
- 论文大纲生成
- 段落撰写
- 引用整合
- 结构润色
- 格式整理
- 研究问题拆解
- 实验方案生成
- 实验记录与结果回写
- AI 绘图与综述配图生成

同时要补充每个技能的：

- 输入
- 输出
- 适用边界
- 深度分层
- 与其他技能的衔接方式

### 2. 实践 Magazine 综述 MVP 目标

本阶段需要选定一个适合 Magazine 综述的主题，并使用现有工具完成一条最小闭环：

- 提出综述主题
- 拉取相关文献
- 形成结构化文献材料
- 产出综述大纲
- 形成综述初稿
- 给出实验设计建议

同时记录：

- 过程中断点
- 人工审核节点
- 工具缺口
- 后续产品化改进点

### 3. 完善 ReadPaper 读文献能力

当前要继续补强读文献面板和检索工作流，重点包括：

- 支持配置可调用的大模型
- 打通从输入到输出的完整检索原理
- 输出检索功能技术方案文档
- 输出检索功能使用文档
- 候选文献摘要完整展示，避免被截断
- 解决实际返回数量不足的问题
- 支持检索历史删除等操作
- 增加更丰富的学术数据库来源
- 在 ReadPaper 下增加文献入库控件
- 保留人工审核节点，避免 AI 输出直接覆盖资产

### 4. 梳理资产层设计

需要统一当前和后续科研资产的结构关系，重点明确：

- 核心资产类型
    - 文献
    - 调研方向
    - 文本块
    - 证据卡片
    - 实验问题
    - 实验文档
- 资产关系
    - 创建
    - 引用
    - 更新
    - 回写
    - 归档
- 文件夹结构
    - 当前规划是否需要调整
    - 不同资产是否需要统一命名
    - 资产如何映射到模块输入输出和流程图

### 5. 进行大模型对比与选型调研

围绕“大模型对比与选型”收集可引用材料，并形成可用结论：

- 优先收集官方文档和学术论文
- 知乎、公众号等仅作为辅助参考
- 对比维度包括
    - 能力
    - 上下文长度
    - 成本
    - 速度
    - 工具调用
    - 科研任务适配度
    - 隐私与部署方式

## 文档任务

本次开发还需要同步补齐文档，至少包括：

- `research/08-data-flow-io.md`
- `research/09-experiment-document-flow.md`
- 文献检索技术方案原理文档
- 文献检索功能使用文档
- 资产目录说明文档
- 核心功能模块图和用户使用流程图整理版

## Demo 验收标准

本阶段的 Demo 至少要满足下面的最小闭环：

1. 用户提出综述主题。
2. 系统拉取文献。
3. 文献写入 `reference/` 或等价资产目录。
4. 生成结构化摘要或文献矩阵。
5. 形成 Magazine 综述大纲与初稿。
6. 生成实验设计建议。

同时要满足：

- 输入、输出、状态和错误提示清晰
- 允许人工审核
- AI 检测结果有明确展示方式
- 不依赖主观判断“AI 味”

## 当前执行顺序建议

1. 先明确技能清单和资产层设计。
2. 再补 ReadPaper 的拉取、检索和入库流程。
3. 然后补文档，确保流程可解释、可交接。
4. 最后以一个 Magazine 综述主题验证整条闭环。
