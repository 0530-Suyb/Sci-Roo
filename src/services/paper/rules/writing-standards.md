# Paper Writing Rules

1. Scientific Writing Style:

    - Use active voice: "We measured..." not "Measurements were taken..."
    - Be concise — remove words that don't add meaning
    - Avoid anthropomorphism: software doesn't "decide" or "believe"
    - Define abbreviations at first use
    - Use precise language: "increased by 15%" not "changed"
    - Delete filler words: "actually," "a bit," "very," "really," "basically," "quite," "essentially"
    - Minimize pronouns: "This result shows..." not "This shows..."
    - Action in verbs: "We analyzed" not "We performed an analysis"
    - Consistent terminology: pick one term per concept and stick with it

2. Structure:

    - Introduction: known → unknown → gap → hypothesis → approach (funnel structure)
    - Methods: enough detail for replication; use subheadings for clarity
    - Results: facts only, no interpretation; point to figures/tables but don't repeat them
    - Discussion: answer the question → contextualize → limitations → implications
    - Keep subject and verb close together (subject-verb proximity)
    - Place emphasis at sentence ends (stress position)

3. Citation Integration:

    - Cite at the point of the claim, not at the end of the sentence
    - Prefer primary sources over reviews
    - Verify every citation has a matching reference and vice versa
    - Use the target journal's citation style consistently
    - NEVER generate BibTeX from memory — always fetch programmatically
    - Mark unverifiable citations as [CITATION NEEDED] and inform the scientist

4. Journal/Conference Compliance:

    - Follow the target venue's author guidelines exactly
    - Match word count limits, section headings, reference format
    - Prepare all required elements: abstract, keywords, highlights, cover letter
    - Check figure specifications (format, resolution, color space)
    - Never modify .sty or .cls template files

5. Abstract Guidelines:

    - Use the 5-sentence formula: (1) what you achieved, (2) why it's hard, (3) how you did it, (4) what evidence, (5) most remarkable result
    - Delete generic openings that could apply to any paper
    - Start with your specific contribution

6. Experiments and Results:

    - For each experiment, state what claim it supports
    - Include error bars with methodology (SD vs SE)
    - Report number of runs and statistical tests
    - Use the Narrative Principle: one clear contribution supported by evidence
    - Cite generously — reviewers likely authored papers you should reference

7. Flagging AI-Generated Content:
    - All AI-generated text must be reviewed by a human
    - Acknowledge AI assistance per journal policy
    - The researcher is always responsible for the accuracy of the content
